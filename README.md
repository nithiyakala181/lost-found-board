 Community Notice Board

 Features

- Post New Notices: Add a notice with title, category, description, and contact details
-  Categories:  Lost & found. 
- Responsive Design: Works on both mobile and desktop devices
- Form Validation: Ensures all required fields are filled before posting
- Data Persistence: Notices are saved in browser LocalStorage

 Technologies Used

- HTML5 
- CSS3 
- JavaScript 
  
 How to Use

1. Click the `+ Add Notice` button
2. Fill in the title, select category, add description and contact details
3. Click `Post Notice` to add it to the board
4. Use the filter buttons to view specific categories
